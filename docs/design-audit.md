# Звірка макетів із реалізацією

Макети лежать у мозку, `Design/*.html` — дванадцять файлів, від 26 до 77 КБ.
Вони не розкладка: у них записана **аргументація**, і саме її легко втратити,
якщо будувати сторінку, не відкривши макет.

> Стан: звірено **2 з 12**. Решта — у CAMP-206.

## Правила, які макети встановлюють для всього сайту

Ці речення варто знати до того, як писати будь-яку сторінку:

- **«Головна — для тих, хто вже нас знайшов.»** Вхід іде з пошуку просто на
  глибоку сторінку. Головна не продає, вона розподіляє.
- **«Герой — це форма, а не білборд.»** Замість фото — мапа з реальними
  кластерами.
- **«Каруселей немає ніде на сторінці.»**
- **«Магазину й кошика немає — і це записано, щоб не повернулось.»**
- **«Гіди — це не блог. Це половина всього трафіку.»**
- Секція «Напрямки» — **«найважливіша секція сторінки, і не для людей»**:
  звичайні текстові посилання, тобто перелінковка для пошукових агентів.

## 11-home.html → `app/page.tsx` (301 рядок)

| секція макета | у коді |
|---|---|
| Герой як форма з мапою | ✅ `<Hero>` |
| Як це працює | ✅ `<HowItWorks>` |
| Напрямки | ✅ `<Countries>` |
| Кемпінги, які варто знати | ✅ `<Notable>` |
| Маршрути | ✅ |
| Атрибуція OSM у рядку | ✅ |
| **Кемпер напрокат** | ❌ **немає** |
| **Гіди** | ❌ **немає** |
| карусель, кошик | ✅ відсутні, як вимагає макет |

🔴 Дві відсутні секції — не оздоба. Оренда це **одна з двох воронок доходу**, і
макет прямо каже, що обидві мусять бути **окремими картками, а не вкладками**.
Гіди — половина трафіку за власним макетом гайдів.

## 09-guides.html → `app/guides/page.tsx` (94 рядки)

Макет 73 КБ, реалізація — `<h1>Guides` і посилання. Бракує всього переліченого:

| вимога макета | навіщо |
|---|---|
| Блок «Коротко» **перед** текстом | «для людей і для цитування» — пряма вимога AEO |
| «Схожі гіди» | перелінковка між 1 256 статтями |
| «Маршрути, де це знадобиться» | місток гайд → маршрут → планувальник |
| Пагінація сторінками, **не** нескінченна стрічка | стрічку пошуковий агент не обійде |
| Ширина рядка в `ch`, інтерліньяж 1.72, 17 px на телефоні | вимірювані, не «на око» |
| «За законом» без джерела **не публікується** | правило контенту, не стиль |
| Пошук і результати калькулятора — `noindex` | щоб не з'їдали бюджет обходу |

## Як читати це далі

Решту десять макетів звіряти тим самим способом: витягнути заголовки й
🔴-правила, зіставити з компонентами сторінки, і кожну розбіжність заводити
**окремою карткою** — щоб обсяг був перелічений, а не оцінений.
