# Система дизайну: числа беремо з теми Fuse

> Усе нижче заміряно з CSS теми і демо-стору `theme7-store1.myshopify.com`
> 08.11.2026. Жодне число тут не вигадане й не «на око».

## Правило, через яке цей файл існує

**Код пишемо свій, вигляд наслідуємо.** Тема — закритий код власника, у git він
не потрапляє; сюди йдуть принципи й числа, а не файли. Але вигадувати власну
систему там, де тема вже дала готову й протестовану, не можна: власник сказав
це прямо — «в темі тобі дали і стилі і розмітку і адаптив і навіть
відтестували код за тебе… стилі і темплейти ми беремо із теми».

🔴 І окремо: **не сліпа віра.** Число з теми — теж твердження. Перед тим як на
нього спертись, воно має бути прочитане з її CSS командою, а не з памʼяті.

## Як перечитати ці числа

```bash
curl -sL https://theme7-store1.myshopify.com/ -o t7.html
grep -ohE 'href="[^"]*\.css[^"]*"' t7.html | sed 's/href="//; s/"$//' | sort -u
# завантажити переліченi файли і грепати по них
```

Токени живуть у `:root` самої сторінки; правила — у `*.build.css`.

## Розкладка

| що | значення теми | у нас |
|---|---|---|
| контейнер | `--container-width: 1704px` | `--container-wrap: 1704px` ✅ |
| вирівнювання | `margin: 0 auto` | так ✅ |
| бічні поля | `4px`, від 1200 — `12px` | **16px / 24px** ⚠️ |
| довгий текст | `840px`, по центру | `--container-read: 840px` ✅ |
| вузькі блоки | 420 / 480 / **540** | `--container-narrow: 540px` ✅ |
| радіус | `--global-border-radius: 16px` | `--r: 16px` ✅ |

Дослівно з теми:

```css
.container{max-width:var(--container-width);width:100%;margin:0 auto;
           padding-left:4px;padding-right:4px}
@media(min-width:1200px){.container{padding-left:12px;padding-right:12px}}

.content .shopify-policy__container{max-width:840px;margin:0 auto;
                                    padding:40px 20px 60px}
@media(min-width:768px){ padding-top:80px;  padding-bottom:100px }
@media(min-width:992px){ padding-bottom:146px }
```

⚠️ **Єдине свідоме відхилення — бічні поля.** У теми вони 4px, бо кожна її
секція додає власні відступи. У нас секцій ще немає, тож дослівні 4px
притиснули б текст до краю екрана на телефоні. Прибрати відхилення тоді, коли
зʼявиться каталог секцій (CAMP-449).

## Пороги

**576 / 768 / 992 / 1200** — заміряно по її ж медіа-запитах
(`min-width:576px`, `min-width:768px`, `min-width:992px`, `min-width:1200px`,
плюс дзеркальні `max-width:575.98px` і далі).

У нас відповідно `--breakpoint-sm/md/lg/xl`. Поріг **576 був пропущений** і
доданий 08.11.2026. `--breakpoint-xs: 375px` — наш власний, у теми його немає.

🔴 Нижче **1200px тема показує бургер** замість меню (`max-width:1199.98px`,
58 вживань). Тобто 1200 — це межа «десктопа» в її термінах, а не наша вигадка.

## Сітка секцій

У теми **немає** системи `row`/`col`. Один контейнер, а кожна секція оголошує
власний `grid-template-columns`: `repeat(2,1fr)`, `1fr 1fr`,
`repeat(auto-fit,minmax(150px,1fr))`, `repeat(5,1fr)`.

🔴 Висновок для нас важливіший за самі числа: **ширину тексту визначає колонка,
у якій він лежить, а не глобальний токен.** Наша помилка була не в тому, що
колонка вузька, а в тому, що колонок немає зовсім — текст або тулиться у
фіксовану смугу, або розтягується на всю сторінку. Тому каталог секцій
(CAMP-449) — не прикраса, а те, що робить ширину осмисленою.

## Вертикальний ритм

Відступи секцій у теми ростуть за порогами, а не стоять: `40/60` → на 768
`80/100` → на 992 `80/146`. Відступи самої секції керуються
`--offset-top-desktop` / `--offset-bottom-desktop` (0 або 12px) і мобільними
(0 або 4px).
